## 📖 功能详述

### 1. 歌手层级映射表 (`pinyin_map.txt`)
简单易编辑。使用本音素器选择歌手时，若读取不到该歌手的映射表文件将自动创建。

#### 🔹 映射 (Mapping)
单个汉字（字素）对应的发音方式（音素），本音素器主要工作原理即把中文歌词字素转化成日语发音音素。

#### 🔹 权重 (Weight)
拼写歌词发音时各音素所占时长，映射表中已写好对应参数。
> **提示**：音素器程序工作时只看比值，故一条映射规则下的权重同时增大或减小相同倍数，映射输出的各音素权重不变，如 `75,25` = `3,1`。

#### 🔹 映射表格式与功能区
*   **映射格式**：`拼音 = 日语假名序列（日语假名1, 日语假名2, ...）, 时值权重（单位：百分比，与前面各项对应）`
    *   *注：为更直观展现占比，采用权重和 = 100，修改时可忽略此书写习惯。*

*   **映射表功能区 (Onset Protection / 音头保护)**：
    VCV 辅音如 し（sh）的起始部分会被挤占，导致发声不连贯自然。开启时会把前邻接音符的末尾音素的起始位置提前（增加权重）。

    **参数介绍：**
    *   `ONSET_PROTECTION=bool`
        *   **音头保护功能开关**。控制开启或关闭，默认**开启**。
    *   `OBJECT(S)=し,ふ,sha,shi,shu,she,sho,fa,fi,fu,fe,fo`
        *   **启用保护的作用对象**。上为范例模版，oto音素别名为平假名的写平假名即可（如 し、ふ 会匹配所有含此项的原音及其拗音），罗马字需匹配才能命中（如 shi 不会命中拗音 sha，得全写）。
    *   `MAGNITUDE=val`
        *   **保护的作用等级**。前邻接音符的末尾音素按公式增加提前起始位置的大小。
        *   **计算公式**：`时长增量 = 歌词总时长 × 占比增量`；`占比增量 = 作用等级 × (100 − 末音素权重) ÷ [100 × (100 + 作用等级)]`

### 2. 歌词内 Phonetic Hinting (发音提示)
实时调整发音（包括映射与时值）。

> **前言**：此发音提示**非官方**句法，所以有些许不同。

*   **定义**：歌词字素后加 `[]`，`[]` 内可写音素序列（音素1 音素2 ...）。
*   **不同点**：本音素器的音素序列为日语假名序列（日语假名1, 日语假名2, ...），即映射表的映射格式，且可以后接权重。
    *   *合法格式示例：*
        *   `中[じょ,ん,85,15]`
        *   `中[jo,n,85,15]`
        *   `中[jo 85 n 15]`
        *   `中[na ka]`
    *   *v1.1.0新增：*     
        *   `ai[あ "e い"]`
        *   `ai[あ,e い]`
        *   `ai[85 15]`
